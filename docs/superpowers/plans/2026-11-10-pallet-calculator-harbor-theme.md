# Pallet Calculator Harbor Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Dark theme with "Harbor" (deep blue and teal, square corners, new typefaces, three small motifs, and a silent pixel-art mascot) and give the Light theme the same shapes, type, motifs, and mascot.

**Architecture:** Harbor tokens become named Tailwind colours; the existing `dark:` variant is re-pointed at a `harbor` root class and every `dark:` colour is replaced with a token, so components keep their structure. Shared pieces (`Mascot`, `SproutProgress`, bracket, root-divider, focus-tick classes) carry the identity. Mascot sprites are generated by a dependency-free Node script from text pixel maps.

**Tech Stack:** As Rounds 1 and 2. New dependencies: `@fontsource/exo-2` and `@fontsource/barlow` (font files only). No other additions.

**Spec:** `docs/superpowers/specs/2026-11-10-pallet-calculator-harbor-theme-design.md` ("the spec"). The Round 1 and Round 2 specs still bind everything this round does not change.

**Reference material (not in the repository):** `.superpowers/harbor-package/` holds the design guide PDF, two mockups (`mockups/Harbor-Basic-1440x900.png`, `mockups/Harbor-Full-1440x900.png`), and a generated sprite set (`assets/*.png`, pose reference only). `.superpowers/harbor-theme-prompt/1-yossele-design-sheet.webp` is the mascot design sheet. Where the guide and the spec disagree, the spec wins (spec section 11).

## Global Constraints

- Visual change only: no change to calculations, layout structure, copy, accessible names, test ids, or numbers. The default example still gives 260 boxes.
- Harbor token values, exactly: deep `#1E3347`, panel `#2E4A62`, raised `#35546D`, teal `#3F8F96`, teal-fill `#34767C`, teal-text `#A3CACD`, foam `#E9F1EE`, mist `#B4C8CF`, coral `#E2725B`, coral-text `#F0B5A9`, sand `#D8C49A`, green `#7BCF80`, viewport `#284256`.
- Only the text pairings in spec 4.1 are allowed in Harbor. Green is never text on raised. Text is never dimmed with opacity.
- No pure black, purple, magenta, or pink. Coral marks errors only. No rounded corners, shadows, gradients, glow, blur, or bevels in either theme.
- Light keeps its current colours exactly; it changes only in shape, type, motifs, and mascot.
- Fixed 3D load colours never change: cartons `#D9A066` / `#C68642`, pallet `#B08A5A`, envelope `#3B82F6`, product and selection colours.
- Mascot colours, exactly five: `#945743`, `#79432F`, `#35403A`, `#7BCF80`, `#99E550`. The mascot is decorative: `aria-hidden`, no name, no caption, and only in the placements of spec 7.2.
- PNG, CSV, and JSON exports are unchanged. The PDF changes only by one mascot image on page 1.
- three.js and jsPDF stay in their lazy chunks. Fonts are bundled, not fetched from another site.
- Engine and domain code (`src/engine`, `src/domain`) is not touched in this round.
- Branch `claude/pallet-calculator-harbor-theme`. Commit after every task; push with `git push -u origin claude/pallet-calculator-harbor-theme`. Do not open a pull request.
- Every task ends with `npm run typecheck && npm run lint && npm test` passing.

## Review Focus

1. **A browser that remembers the old theme** (`dark` or `system` stored, or a hand-edited value): must open in Harbor with no flash and no error. Tests in Task 2.
2. **States that only appear occasionally** (error with Retry, "nothing fits", out of date, limited search, disabled Export items, an invalid field in a dialog, the preset "Modified" badge, target badges): each must be restyled, not left in old colours. Checked by the leftover scan in Task 4 and by eye.
3. **Narrow and short windows** (1280 × 720 and 1100 × 600): capital headings with wide letter-spacing and the header mark must not push controls off screen or wrap the header. Browser check in Tasks 3 and 6.
4. **Reduced motion and no fonts** (`prefers-reduced-motion`; font files blocked): the sprout and working mascot are static; text is readable in the fallback font with no layout break. Tests in Tasks 5 and 6, check in Task 3.
5. **Exports made from Harbor**: the PNG and the build-sheet pictures stay light, and the scene returns to Harbor afterwards. Test and browser check in Task 7.

### Task 1: Mascot sprites

**Files:** Create `tools/mascot/poses.mjs`, `tools/mascot/build.mjs`, `tools/mascot/build.test.ts`, `src/assets/mascot/*.png`, `public/favicon.png`; add npm script `mascot` (`node tools/mascot/build.mjs`).

**Produces:**

```js
// poses.mjs
export const PALETTE = { B: '#945743', S: '#79432F', K: '#35403A', G: '#7BCF80', E: '#99E550', '.': null };
export const POSES = { idle, working1, working2, working3, concerned, headerMark, print }; // each: 32 strings of 32 chars
export const TAB_ICON; // 16 strings of 16 chars
// build.mjs

export function buildAll(outDir, publicDir): void;
```

Output files: `idle.png`, `working-1.png`, `working-2.png`, `working-3.png`, `concerned.png`, `header-mark.png` at 32 × 32 (scale 1); `print.png` at 512 × 512 (the print grid at scale 16); `public/favicon.png` at 32 × 32 (the 16 × 16 tab icon at scale 2). Generated files are committed.

**Rules:**

- **Idle** is the "Existing key — construction study" drawing on the left of the design sheet, traced pixel for pixel: 17 wide × 22 tall, centred horizontally in the 32 × 32 cell with its feet on row 30. Trace it by sampling the sheet image on the drawing's own pixel grid (measure the pixel size from the leaf and limb edges); then check the result against the sheet's labelled features: hollow head opening with one eye mark at each inner side edge; triangular bandana three rows deep; two arms from the shoulders and two inner legs, all four ending on the same row; a stem with two leaf tips, the left one higher; one shoot outside the left shoulder; shade colour on the right side and underside only.
- **Working 1/2/3:** idle with both leaf tips raised one pixel and the shoulder shoot at left, centre (idle position), and one pixel right. Body and head are identical in all three.
- **Concerned:** idle with both leaf tips lowered and drooping outward by two pixels, and the head shifted one pixel left with the stem following. Limbs unchanged.
- **Header mark:** head ring, stem, and the two leaf tips only, centred in the cell.
- **Tab icon:** the head ring with stem and leaves redrawn on 16 × 16 so the ring opening is at least 2 × 2 and both eye marks are present.
- **Print:** the idle figure with both leaf tips raised one pixel.
- No outline, no colours outside the palette, no semi-transparent pixels.
